# 숫자 하나가 어디서 오는지 보기

Ubuntu의 `agent-admin` 셸에서 실행한다. CPU·메모리·디스크는 이 환경에서 보이는 시스템 자원이다. 로그의 PID는 점검한 앱을 식별하고, 세 사용률은 시스템 상태를 기록한다.

## 디스크 · 명령 출력에서 한 칸 고르기

```bash
df -P /
df -P / | awk 'NR == 2 { print $5 }'
```

첫 줄에서 `/`는 루트 파일 시스템이다. 표의 두 번째 줄에서 다섯 번째 값인 `Use%`를 찾는다. 두 번째 명령은 그 작업을 자동화한다. `|`는 왼쪽 출력을 오른쪽 명령의 입력으로 넘긴다. `awk` 안의 `NR == 2`는 두 번째 줄, `$5`는 다섯 번째 칸이다. 앞에서 배운 Bash 함수의 `$1`과 달리, 작은따옴표 안의 이 식은 awk가 읽는다. `get_disk_usage`는 이 값에서 퍼센트 기호도 지워 숫자만 출력한다.

## 메모리 · 전체에서 사용 가능한 양 빼기

```bash
grep -E '^(MemTotal|MemAvailable):' /proc/meminfo
```

`/proc/meminfo`는 리눅스가 현재 메모리 정보를 보여주는 파일이다. `grep`은 두 이름으로 시작하는 줄을 골라 준다. `MemTotal`이 1,000이고 `MemAvailable`이 900이면 사용률은 `(1000 - 900) / 1000 × 100 = 10%`다. `get_mem_usage`가 이 계산을 한다.

## CPU · 1초 동안의 변화 읽기

```bash
head -n 1 /proc/stat
sleep 1
head -n 1 /proc/stat
```

`cpu`로 시작하는 줄은 부팅 후 누적된 시간이다. `get_cpu_usage`는 두 번 측정해서 **그 사이에 늘어난 시간**을 계산한다. 전체가 100만큼 늘고 유휴 시간(`idle + iowait`)이 80만큼 늘었다면 사용률은 20%다.

## 어떤 값에서 경고할까?

`show_resources`는 세 사용률을 출력하고 `warn_if_above`에 차례대로 건넨다. 기준은 CPU 20%, 메모리 10%, 디스크 80%다. 예를 들어 디스크 80%에서는 경고가 없고, 81%에서는 경고와 함께 측정값을 기록한다. 높은 부하가 발생한 순간의 값을 보존하기 위해서다.
