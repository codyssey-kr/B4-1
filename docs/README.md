# B4-1 문서 안내

서버의 보안, 권한, 실행 환경을 구성하고 `monitor.sh`로 상태 점검을 자동화한 과제의 설명 자료다.

## 읽는 순서

| 순서 | 문서 | 내용 |
|---|---|---|
| 1 | [배경지식](01-background.md) | 과제를 이해하는 데 필요한 리눅스 운영 지식 |
| 2 | [구현 설명](02-implementation.md) | 요구사항별 구현 내용, 설계 이유, 문제 해결 기록 |
| 3 | [평가 대비](03-evaluation-guide.md) | 체크리스트 19개 항목의 시연 방법과 답변 |
| 4 | [판단 필요 사항](04-decisions.md) | 제출 전에 직접 결정하거나 확인할 내용 |

## 프로젝트 구성

| 경로 | 역할 | 제출 |
|---|---|---|
| `B4-1-수행내역서.md` | 설정 기록과 필수 증거 | 제출 |
| `monitor.sh` | 상태 수집 및 로깅 스크립트 | 제출 |
| `docs/` | 학습과 평가 준비 자료 | 보조 |
| `scripts/start-b4-1.sh` | 재부팅 후 실습 환경 복구 | 보조 |
| `scripts/verify-b4-1.sh` | 구현 항목 52개 자동 점검 | 보조 |

## 빠른 확인

프로젝트 루트에서 실행한다.

```sh
./scripts/start-b4-1.sh
./scripts/verify-b4-1.sh
```

마지막 줄에 `결과: PASS 52 / FAIL 0`이 나오면 평가 가능한 상태다.

## 현재 상태

- 필수 요구사항 구현과 증거 수집을 마쳤다.
- 체크리스트의 설명 항목은 [평가 대비](03-evaluation-guide.md)로 준비했다.
- 선택 과제인 보너스 1, 2는 구현하지 않았다.
